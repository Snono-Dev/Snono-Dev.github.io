# بورتوفوليو GitHub Pages

موقع بورتوفوليو عربي ثابت، لا يحتاج إلى أي بناء أو خادم. صفحة المشاريع تجلب المستودعات العامة مباشرةً من GitHub API عند فتح الموقع.

## التخصيص

افتح `config.js` وعدّل:

- `username`: اسم حساب GitHub. يمكن تركه فارغاً عند النشر على `USERNAME.github.io`؛ سيتعرف الموقع على الاسم من الرابط تلقائياً.
- `name` و`role` و`email` و`quickChatUrl` (رابط جلسة محادثة سريعة مثل Calendly أو WhatsApp).
- `maxProjects`: عدد المشاريع المعروضة.

عدّل ملف `about.md` لعرض نبذتك العربية، و`about.en.md` للنسخة الإنكليزية. يدعم الملفان العناوين والقوائم والنص العريض. ويوجد زر للتبديل بين العربية والإنكليزية. تعرض صفحة المشاريع الأحدث والأشهر بحسب عدد النجوم.

## تعديل الموقع من about.md

أصبح `about.md` مركز تعديل بيانات الموقع العربية، و`about.en.md` للنسخة الإنكليزية. عدّل القيم بين `---` في بداية الملف: `name` و`role` و`github_username` و`email` و`session_id` و`eyebrow` و`hero_title` و`hero_emphasis` و`hero_copy` و`skills` (المهارات مفصولة بفاصلة). أمّا النص بعد `---` الثاني فهو محتوى قسم «عني» نفسه.

## التواصل عبر Session

ضع معرّفك الكامل في `session_id` داخل `about.md` و`about.en.md`، مثال: `session_id: 05...`. سيظهر زر «محادثة سريعة» ويفتح صفحة تحتوي معرّف Session ورمز QR للمسح، إضافة إلى رابط لفتح Session مباشرةً.

## صفحات المشاريع

كل بطاقة مشروع تفتح صفحة تفاصيل ديناميكية. ضع `README.md` للعربية و`README.en.md` للإنكليزية في جذر المستودع؛ ستُعرض محتوياتهما تلقائياً حسب لغة الزائر. أزرار «المستودع» و«زيارة الخدمة» تظهر في صفحة المشروع، ويُؤخذ رابط الخدمة من `service_url` داخل `about.md` الخاص بالمستودع.

## ملف كل مشروع

ضع ملف `about.md` (للوصف العربي) و`about.en.md` (للوصف الإنكليزي) في **جذر كل مستودع** تريد تحسين عرضه. الصيغة الثابتة هي:

```md
---
visible: true
service_url: https://your-service.example
repository_url: https://github.com/username/repository
---

وصف قصير للمشروع يظهر في بطاقة البورتوفوليو.
```

- `visible`: خاصية للتحكم بالظهور (افتراضياً `true`). يمكنك وضع `visible: false` أو `visible: no` أو `status: hidden` لإخفاء المستودع مؤقتاً من البورتوفوليو بدون حذف ملف `about.md`.
- `service_url`: اختياري ويُظهر زر «زيارة الخدمة»، مثل رابط GitHub Pages أو الموقع المنشور.
- `repository_url`: اختياري أيضاً؛ إذا لم تضعه سيستخدم الموقع رابط GitHub الخاص بالمستودع تلقائياً. يُعرض المستودع في الصفحة الرئيسية فقط إذا كان يحتوي على ملف `about.md` أو `about.en.md` وكانت خاصية `visible` مفعلة.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً وارفع هذه الملفات إليه.
2. من **Settings → Pages** اختر النشر من فرع `main` والمجلد `/(root)`.
3. افتح الرابط الذي يوفره GitHub.

> لا يمكن لواجهة GitHub العامة عرض المستودعات الخاصة، لذلك ستظهر المستودعات العامة فقط.
